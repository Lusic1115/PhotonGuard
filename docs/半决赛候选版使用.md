# 半决赛候选版使用

本版为 `0.2.0rc28`，沿用已有单缝模型与知识库。双击「启动工作台.bat」，首次使用需安装 Ubuntu WSL 并准备环境。独立知识包可直接使用 Python 3.10+ 启动。

## 主任务：把中央亮区变宽

在首页「你想解决什么问题？」粘贴：

> 使用633 nm光和200 mm焦距透镜，希望中央亮区全宽10±0.2 mm。只允许改变缝宽，范围15—35 μm，缝高100 μm。采用教学模型，其他设置请帮我安排。

点「开始这个任务」。连接自己的 AI 后，同意发送本轮目标，选择「AI 整理并预览」。查看固定条件与候选，再点「创建计划并核对」，勾选计划确认并计算。本地整理也可独立使用。

完成后打开「光学助教」，向 AI 提问：

> 让中央亮区再宽50%，光源和透镜不变。

核对解析预览中的改变项，点「准备实际验证」，再核对并批准计算。结果页上方会出现两版比较，点「专注查看」展示二维图和叠加剖面；退出用「返回实验」或 Esc。默认各自峰值归一化用于比较形状，也可选择共同入射光强标尺。两张图共用坐标范围。

继续问：

> 为什么缝更窄，亮区反而更宽？结合这两版结果，用两三句话说明。

解析全宽由登记几何公式计算，二维图与剖面来自批准后的 FFT 数组，实际后端和原始记录可在展开区域查阅。整组记录可使用任务的导出入口保存。

## 独立学习：FRET 两点比较

进入「光学知识库 → AI 学习助教」，提问「什么是 FRET？」。展开「比较两个距离的 FRET 效率」，输入归一化距离 A=0.7、B=1.6。图形和数值按登记公式更新。点击「解释当前比较」，页面会用当前控件数值生成可见的问题，再发给已连接的 AI；本地模式只查核本地依据与公式结果。

知识正文与来源可展开阅读，学习摘要可下载保存。
