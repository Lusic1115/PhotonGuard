# 源码、版本与文件核对

当前版本为 `0.2.0rc28` 预发布版。产品基于应用源码 `03f3a95af52317fa9d57d018fa3b07d65d1b2da5`，公开分发整理了文档、测试名称和界面说明，计算与学习功能沿用该版本。

- `app/SOURCE_MANIFEST.json` 列出本副本的源码文件及 SHA-256，启动器逐项核对。
- `app/MANIFEST.json` 覆盖源码清单、启动器及运行配置。
- `GITHUB_FILES.json` 覆盖仓库分发文件，清单本身除外。
- 历史案例按原任务、参数和保存结果分别记录；文件身份变化不改写原来的实验数据。

源码中的历史 `.sha256` 清单记录早期快照；本次下载文件使用上述三份当前清单核对。

修改源码时，在独立开发目录按[源码说明](../app/source/README.md)运行。面向使用者的启动包应重新生成匹配的清单；文件校验报错时先检查下载和解压是否完整。

个人任务在 `app/data/`，日志在 `app/logs/`。更新前备份自己的任务和导出记录；这些目录及 API Key 不属于公开分发文件。
