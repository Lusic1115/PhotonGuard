# PhotonGuard 学习与实验指南

在知识库的「AI 学习助教」提问后，匹配的单缝焦平面问题可以打开「带着这个问题去验证」。核对资料、保存待核对计划，再到实验工作台批准计算。膜厚问题可从同一处进入已有数据导入或教学模拟。已保存结果页提供「带结果回到原学习问题」，后续解释与下载摘要可带上实际结果和原来采用的知识版本。

## 启动与回退

完整解压运行包。在 Windows 上双击 `启动工作台.bat`。首次使用且尚未安装 WSL 时，先运行 `首次准备环境.bat`，按提示完成 Ubuntu 初始化。工作台数据保存在当前解压目录的 `app/data/workspace`。结束使用可双击 `停止工作台.bat`。

回退时可解压自行保留的旧版本，并使用该版本的启动脚本。每个解压目录有自己的本机数据。需要跨版本保存资料时，先在当前版本下载实验链和学习摘要。

## 试一段连续学习

- 光纤可从现象入手。问「光纤里光从太斜的方向进不去，这叫什么」，再指定直阶跃多模光纤、纤芯 1.49、包层 1.46、空气入射。后续只改外部介质折射率时，核算保持芯包参数。
- 问「FRET 距离变化会怎样」，展开「比较两个距离的 FRET 效率」，调整两处 r/R₀，查看效率、百分点差和相对变化。图采用弱耦合点偶极公式。
- 在答复下方继续追问，或从历史选择一轮再问。工作台侧栏的「展开到学习页」保留已有问题、回答及可用的实验摘要。独立知识库可导出单缝验证草稿。

## 查阅光学知识

在工作台顶部点击「光学知识库」。可按主题或直接搜索，例如「束腰」「阿贝成像」「光纤的数值孔径」。打开条目后可查看公式、条件、例子、前置知识和来源。

可按知识包筛选。专题包括光学数学与统计、电磁场与介质界面、非线性极化与频率转换。搜索时有匹配的专题会单独显示。正文可展开「来源与许可」和「核心结论与依据」，查看原文定位、推导和练习示例。

进阶条目覆盖超快脉冲、非线性耦合波、光纤及集成光学。相关专题附有结构示意或公式图解，可点击图下的问题直接进入对应小节。跨主题比较时可展开「符号与单位约定」。在支持的条目中可定位到现有工作台案例，审核和计算沿用工作台的正常操作。仅学习时可解压独立知识包，用 Python 3.10 或更新版本启动。

在「专题讲解」打开一份完整讲解。可先选中节内的一句话或公式，再点击「问这一节」。连接 AI 后，可选择直接讲本步或展开推导。试问「比较 3 pW/√Hz、16 Hz 与 5 pW/√Hz、4 Hz 的实际噪声，按白噪声与等效带宽」，下一轮可只说「第二台带宽改成 9 Hz 呢？」。登记公式会显示代入和单位。学习对话保存在当前工作区，刷新页面后可继续，也可下载学习摘要。

「查本地依据」可离线使用。连接 DeepSeek 后自动返回提问区。点击「请 AI 串讲」先读讲解，再查看核对资料。未命中条目时，助教会标明讲解来自 DeepSeek；可接着追问，或直接提出新问题。条目中的实验入口可打开工作台。知识包的安装、撤回和字段说明见[知识包说明](知识包说明.md)。

## 从目标开始做单缝实验

1. 在首页「你想解决什么问题？」填写目标并点击「开始这个任务」。也可在下方教学案例打开单缝任务。中央亮区全宽指左右第一暗纹的距离，表单也可明确选用中心到单侧第一暗纹。
2. 选择「本地整理并预览」，或连接 DeepSeek 后同意发送本轮目标，选择「AI 整理并预览」。程序根据已核对条件在范围内生成缝宽候选。固定目录按所填值比较；结果表会标出最接近目标的值。
3. 如果缺少必要条件，展开「查看或补充已知条件」。学习时可选择带出处的教学预设。实际装置需要确认波长、焦距、缝高和焦平面几何。高级数值设置里可核对网格和输入孔径窗口。
4. 点击「创建计划并核对」，查看目标、固定条件和计算预算。勾选同意后，点击「确认计划，开始计算」。曲线与二维图来自实际 FFT，图上虚线标记解析第一暗纹。
5. 在候选下拉框选择要看的图。工作台使用共同光强标尺。目标表的宽度来自理想单缝公式，FFT 的二维数组与双网格检查分别保存。

可直接使用的目标

> 使用 633 nm 光和 200 mm 焦距透镜，希望中央亮区全宽 10±0.2 mm。只允许改变缝宽，范围 15–35 μm。采用教学模型，其他设置请帮我安排。

## 询问助教并验证

- 点击「光学助教」打开侧栏，可问「什么是瑞利长度」，接着问「没懂，换一个例子」或「这里为什么是平方」。可点「直观看懂」或「公式推导」切换讲法，也可展开本次学习对话回看。选择「查本地知识」可离线使用。
- 首页侧栏的「浏览光学知识库」可进入独立阅读页。围绕已保存的实验结果提问时，可继续使用工作台侧栏里的助教。
- 侧边助教支持查询完整知识库，也可结合当前图表和结果。点击「向 AI 提问」时，工作台发送本轮问题、必要结果摘要和相关讲解。
- 对单缝结果提问「532 nm 会怎样？先解释，不要计算」。先看解析预览。决定验证时点「准备实际验证」，核对新旧波长和沿用条件，再批准实际计算。结果保存后可点击「叠加来源与本次 FFT」。
- 「保持条件，重评目标」适合只改容差。复用记录会注明来源和新增求解次数。要解释旧图，先打开对应的历史结果。
- 单缝结果区可拖动波长、焦距、缝宽和缝高。橙色虚线是解析预览，紫色虚线对应保存条件。选「准备实际验证」后按当前计划另行批准。切换共同标尺、峰值归一化和分贝显示时，曲线及二维图的标尺随之更新。
- 单缝两版对照中的「为什么这样变」给出每次只改一项的解析值和合并倍率。可准备一项对照，或从「恢复来源版本的效果」选明参照候选、评价尺度、容差和可用缝宽。固定目录无达标项时显示最接近项。来源已完成两阶段时，可以明确另开一轮验证，按新计划批准。
- 「从猜想到验证」可保存对下一轮的猜想，再把问题交给侧栏。批准对照后记录观察，在「总结这几次实验」查看并导出对应条件、预览和实际结果。
- 薄膜任务可以从一份教学反射率或用户 CSV 开始。核对厚度范围、保留候选和允许波长，再选择补测。用户 CSV 路径在第二份文件上传并核对后，单独批准联合拟合。高斯教学任务可以登记手边的透镜与屏幕位置，按批准的组合比较屏幕半径与束腰。双缝任务可以分别调整缝宽、中心距或相位。
- 回看膜厚补测时使用「仅解释和回顾」。需要换目录或准备下一步时，选择「修改条件或规划下一步」，并说清本轮要采用的目录。新增观测纳入联合拟合后，结果页同时给出导入值、旧候选预测和联合后保留的候选。

## 带走记录

「导出本次记录与可重跑配置」保存计划、实际数组、数值核对和表格。「下载学习记录」概括目标、条件、改动、观察和所用原理，任务导出中也包含该记录。教学和单缝目标任务可以在结果页保存本版观察。对话按结果版本本地保存。
