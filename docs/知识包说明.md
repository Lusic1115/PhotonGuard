# 光学知识包

工作台的 `/knowledge` 页面离线检索内置条目和本地专题包。内容包独立于工作台版本。内置的历史知识卡保留原编号，新增专题内容的格式见 `app/source/photonguard/experiments/knowledge_data/pack-optics-core.json`。

光纤与集成光学、探测与测量、量子基础各有独立内容包。可在页面按包筛选，同一条正文同时保留所属主题、适用条件和版本。新增条目的源资料按章节或 PDF 阅读器页序定位。在线文档使用原始地址和主题定位。

## 内容与许可

一个包有 `id`、`version`、`sources`、`entries`，可附 `topics`。发布条目需要定义、正文、例子、适用条件、常见混淆、出处和校对记录。公式同时记录符号和单位。编号在主题包之间保持唯一，前置和关联条目要在有效索引中可解析。草稿可随本地包保管，公开目录和搜索只读取已发布内容。

[示例专题包](示例专题包.json) 包含两篇计算练习、三节完整专题与一张原创图解。安装后搜索「群延迟换算练习」，可打开条目和专题，从图解追问对应小节。图解以有限坐标点描述曲线，页面生成 SVG。源码及条目出处见包内记录。示例包 ID 为 `extension-modal-delay-practice`。

内置新增正文为 PhotonGuard 原创讲解，按项目的 GPL-2.0-or-later 授权。来源记录包含原始资料作者、出版或课程版本、定位、核对日期、权利和文件指纹。第三方教材正文、翻译、图像和讲义文件通过原站获取。自行制作专题包时，须按来源条款核实任何复制或改编内容。

## 校验、安装与撤回

用运行工作台的 Python，从 `app/source` 执行下列命令。将示例路径换为自己的知识包和工作台数据目录。

```sh
python -m photonguard.experiments.knowledge_pack --validate /path/to/pack.json
python -m photonguard.experiments.knowledge_pack --workspace ../data/workspace --install /path/to/pack.json
python -m photonguard.experiments.knowledge_pack --workspace ../data/workspace --remove example-pack
```

安装前完整验证索引，失败时继续使用原内容。已有同版本内容发生修改时，请提高知识包版本。升级内置专题后，撤回本地版本即可恢复随包附带的内容。替换其他专题包前可保存旧文件，必要时重新安装。新一轮搜索读取当前安装版本，浏览器同一标签中保存的上一轮学习依据会显示原版本并提示开启新问题。
